# 安装与使用

## 第一次安装

1. 安装 [Node.js](https://nodejs.org/) 的 LTS 版本，要求至少 22.12；安装后重新打开终端
2. 在仓库页面点击 **Code → Download ZIP**，解压到你准备长期保存的位置；不要在压缩包里直接运行
3. 打开解压后的目录，确认能看到 `package.json` 和 `首次安装.cmd`
4. 双击 `首次安装.cmd`，等待安装完成；首次需要联网下载依赖、浏览器和基础模型
5. 最后出现 `[Y/N]` 时，选 `N` 可以先用基础分类；选 `Y` 会额外准备数 GB 的本地视觉模型，可能打开 Ollama 安装向导

看到 `Base setup complete` 表示基础安装已完成。下载耗时取决于网络；有错误时保留窗口里的第一条错误，不必删除整个项目重装

也可以用 Git 下载：

```powershell
git clone https://github.com/Old-Doggy/lenssort-ai.git
cd lenssort-ai
.\首次安装.cmd
```

## 日常整理照片

1. 先把本批照片放进来源文件夹
2. 双击 `启动网页控制.cmd`，保留启动窗口；默认网页地址是 `http://127.0.0.1:4317`
3. 在“设置文件夹与设备”中选择来源目录和结果目录，两者不能相同、互相包含；建议使用单独的结果目录
4. 设备先选自动选择；想试用加速设备时再选择当前电脑检测到的选项
5. 模型可以先选基础分析；安装了视觉模型后再按资源建议选择
6. 点击“一键筛选”，等待“分类完成，已自动停止”

分类结果是原图的副本，按类别放在结果目录。分类结束后再加入来源目录的新照片不会自动继续处理，需要重新点“一键筛选”

## 检查结果

- 点击分类标签切换照片，点击照片或“查看详情”打开大图
- 分错时，在详情的人工修正区域选择正确分类，确认后移动分类副本，原图保持原位置
- “删除分类副本”需要确认，只删除分类产物，不删除来源原图；主动删除的副本不会在下一次运行时自动恢复
- 在文件管理器删除了原图或结果副本后，点“刷新当前文件夹”核对磁盘现状
- “辅助推荐”需要先完成分类，依据只在推荐照片详情中展示，最终保留哪些仍由你决定

## 可选：准备视觉模型

双击 `安装本地视觉模型.cmd`，完成官方 Ollama 安装向导，等待默认 `qwen3.5:4b` 下载完成。安装后重新打开网页控制；已安装的 Ollama 会在启动时尝试自动启动或复用，无需每次手动启动

模型文件不包含在项目 ZIP 中。安装需要网络；照片推理使用本地模型，项目不连接云端图片 API

想主动安装其他支持的模型，在项目目录运行：

```powershell
npm run setup:vision -- --model=gemma3:4b
```

或使用 `--model=qwen3.5:9b`。9B 更占内存和显存，先看网页建议再运行，不保证效果一定更好

GPU 设备探测还需要可用的 Python。NPU 需要对应硬件、驱动和 Windows ML 环境，不是下载后所有电脑都能启用；见[技术说明](technical-overview.md)

## 退出与更新

分类结束后，在启动窗口按 **Ctrl+C** 停止服务，必要时按提示确认，再关闭窗口。只关闭浏览器标签不会停止服务；不需要安装开机启动

使用 Git 的用户，可先备份自己的源码改动，再执行 `git pull --ff-only` 并重新运行 `首次安装.cmd`，让依赖和网页产物一起更新。重新安装时会跳过已校验的基础模型资源

使用 ZIP 的用户，建议解压新版到新目录并重新安装，确认原图与结果目录保存在旧项目之外。不要直接删除含有自己照片或结果的旧目录；新目录首次打开时重新选择照片与结果路径

更多排障步骤见[常见问题](troubleshooting.zh-CN.md)
