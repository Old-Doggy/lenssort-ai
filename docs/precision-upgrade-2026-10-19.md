# 有限精度升级计划（2026-10-19）

## 目标与边界
- 用户通常处理几百张照片：精度优先，速度次之；网页一键启动，当前批次完成自动停止，不监听新增照片。
- 已核实 RTX 5070 Ti Laptop GPU 总显存 12227 MiB；空闲显存随其他程序变化，不把总容量当可用容量。
- MobileNetV4 是 ImageNet 闭集快速分类器，不适合单独决定人物、动物、天空等开放照片语义。保留已验证 NPU 快路径，不把更大模型自动称为更准。
- Gemma 3 4B 是现有视觉基线。最多增加两个稳定视觉候选；官方资料已核实存在 Qwen3.5 4B/9B 视觉版本，因此本轮选这两个、关闭思考进行同条件比较，不另下载 Qwen3-VL。是否采用由本机多图测试决定。
- 新模型只下载权重，不上传照片；默认不调用云端。人工标签、删除记录、原图保护不得回归。

- [x] 提示词先看图再判断，不向模型灌输旧分类；不使用自报 confidence 作为准确概率。

### R4 精选和描述的有限修复
- [x] 精选优先专用审美而非技术参数：复用现有 LAION 与 MUSIQ-AVA，核实专用替代方案部署成本；不再无限下载评分器。
- [x] 夜景/高调照片不因曝光一票否决；先做近似组内择优，再跨组排序。VLM 不把自报数值当校准审美分。
- [x] 网页显示精选阶段进度、评分来源、故障提示、相对排名和入选理由；评分失败不伪造分数，低内存安全回退。

## 当前停止点
R1-R5 的有限实现与回归已完成；生产默认不再按“已安装模型最大”自动选择。网页可选择基础分析、Gemma 3 4B、Qwen 3.5 4B、Qwen 3.5 9B，默认自动安全选择优先4B；低配/未知资源保护性降级。精选模型搜索停止在 LAION + MUSIQ-AVA 组合，不再继续下载或替换评分模型。当前唯一外部步骤是用户盲选确认。
