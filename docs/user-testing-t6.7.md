# T6.7 / F7 三轮真人试用：网页自动文件夹主线

版本：2026-10-10。替代旧版手动导入、三模式、相似组操作和 JSON/CSV 下载任务；旧版自动测试不算当前真人记录。状态：等待真实参与者，以下是空模板，不是测试结果。

## 1. 主持人准备

1. 在项目根目录运行 `启动网页控制.cmd`，在 Chrome 或 Edge 打开本机 `http://127.0.0.1:4317`；不是直接双击 HTML，也不是 5173 开发预览。不能把本机地址发给另一台电脑作为测试链接。
2. 为本轮单独建立来源和输出文件夹。开始前确认没有监听私人相册，不覆盖日常输出目录；设置只能在停止筛选后改。保留服务窗口，关闭服务会停止监听。
3. 先用公开授权或自行制作的样本验证流程。真人选片判断使用参与者自选、同意在本机分析的真实照片，原图由参与者保管，不发送给代理或提交仓库。
4. 准备 6–20 个样本及匿名编号，可额外复制一个相同内容文件测试去重。生成图/变换副本只能说明操作流程，不能证明真实分类准确率或审美满意度。
5. 记录设备、版本、照片数量、任务顺序、开始/结束时间。模型等待单列，但端到端用时必须包含等待与人工复核。
6. 默认不预先解释两个按钮，以观察用户能否独立理解；发生求助先记录，再提供一次明确提示。目录/设备的高级配置属于首次设置成本，不能假装没有。
7. 不开启公网、不修改浏览器安全策略。出现照片丢失、处理失败、明显卡死或意外上传迹象，立即暂停该轮并保留失败记录。

## 2. 三轮有限执行与停止步

- R1 发现问题：一位真实用户做 A–E，记录第一处卡点和原话；最多 20 分钟。完成后停止，反馈问题，不由开发者补写意见。
- R2 有限复测：如 R1 存在阻塞问题，只修该问题后复测；若没有修改，也如实记录同版本复测。最多 20 分钟，记录熟悉效应和样本变化，停止后确认问题解决或保留未解决状态。
- R3 独立验证：优先另一位真实用户做 A–E。若仍为同一人，写“1 人 3 轮”，不得写“3 名用户”。最多 20 分钟，汇总后停止。
- 三轮不是无限优化循环；只允许阻塞 bug 的一次有限复测，不增加第四轮产品扩张。没有参与者就保持等待，自动化浏览器/视频不能替代真人。

## 3. 任务 A–E

### A 首次设置与启动
- 请用户说出页面用途，找到一键筛选。
- 首次在高级设置填写来源、输出和设备，然后收起设置并启动。观察是否误以为需逐张网页上传。
- 达成：界面显示正在筛选，来源目录准备完成；记录求助次数和首次设置时间。

### B 放入目录后自动分类
- 将样本复制到来源文件夹，不手动给每张照片分类。
- 等待写入稳定后卡片出现，切换分类标签，并指出一张分类不确定/不同意的照片。
- 达成：结果出现、输出目录有分类副本；区分模型识别错误和文件未处理错误。

### C 一键挑好看与边界理解
- 点击一键挑好看，查看精选标签、数量和原因。
- 请用户复述：它目前按清晰度、曝光和主体信号初筛，不是审美模型，也不判断闭眼。
- 若本轮有合格真实样本，先保存初次精选匿名名单，再请用户判断愿意保留哪些；没有精选如实记 0 张，不把无结果当 100% 接受。

### D 找到实际产出
- 用户打开输出目录，确认分类副本，以及 `精选\<批次哈希>` 和 `精选\selection.json`。
- 确认原图仍在来源目录。当前主线没有网页 CSV/JSON 下载按钮，也没有照片压缩包下载；磁盘清单不等于网页下载。
- 再点一次一键挑好看，观察完全相同内容只精选一份、同一批次复用。没有新的合格照片不要求产生新的结果。

### E 停止、恢复与信任
- 点击停止筛选，复制一个新样本，确认不会继续自动处理。
- 重新启动，观察新样本被处理、已有记录保持；刷新网页确认目录和状态。
- 请用户说明原图是否会删除、照片是否上传，以及在哪里看到说明。关闭网页不等于关闭后台服务；停止按钮或关闭服务才停止监听。

## 4. 指标口径

| 指标 | 记录方法 | 边界 |
|---|---|---|
| 任务完成情况 | A–E 各完成/未完成/未测；卡点原话 | 不预设通过率 |
| 首次设置与端到端时间 | 总秒数、模型等待秒数、求助次数 | 不从总耗时扣等待后宣称节省 |
| 精选主观接受率 | 首次精选中愿保留数 / 实际精选数 | 分母为0或无真人判断写未测；不是分类准确率 |
| 分类意见 | 匿名照片编号、实际分类、人工意见 | 不取代 F5 六类人工标注评估 |
| 边界理解度 | 0不理解/1部分/2准确复述 | 保留用户原话摘要 |
| 满意度/隐私信任 | 1–5及原因；不愿回答写未测 | 少数参与者不是总体结论 |

若测节省时间，手工与工具必须是同一目标（N 张整理到类别并挑 K 张），记录两次起止、顺序、最终名单及版本。不同用户交替顺序以披露熟悉效应；不可比则不计算节省率。可比且手工秒数大于0时才算 `(手工秒数-工具秒数)/手工秒数`，负值如实保留。
