# P2 模型选择报告

- 状态：completed-with-boundaries
- 样本：41 张；带风险标签 29 张
- 范围：人物检测、场景语义、审美排序候选的隔离基线，不修改生产主链路。

## 定案组合

| 能力 | 选择 | 用法 |
|---|---|---|
| 人物候选 | YOLOX Tiny | 发现人物候选；与框面积、置信度、人脸和场景联合门控 |
| 人脸辅助 | MediaPipe Blaze Face/Face Landmarker | 人脸数量、主体证据和后续人像辅助 |
| 场景语义 | CLIP ViT-B/32 | 风景、建筑、城市、夜景、人物环境辅助语义 |
| 审美候选 | LAION aesthetic V1 线性头 | 精选排序信号，不直接等同“好看” |
| 技术质量 | 现有清晰度/曝光分析 | 排除明显技术风险 |
| 重复处理 | 现有视觉指纹 | 连拍/相似图先去重 |

## 基线证据

- YOLOX Tiny：平均 64ms/张；0.25 阈值下 23 张出现人物候选。
- CLIP 场景：41/41 张成功；平均 119ms/张。
- LAION 审美：41/41 张成功；平均 127ms/张。
- 三张“人物漏脸”风险图由 YOLOX Tiny 给出高置信人物候选，说明不能再用“人脸数量为 0”直接判定无人。

## P3 门槛

- 先建立统一中间结果：人物候选、人脸、人景语义、审美分、技术质量、重复组和证据来源。\n- 人物分类采用证据门控：YOLOX 发现人物但人脸为空时不得直接判无人；低置信度保留待确认。\n- 精选排序先去重，再按审美与技术质量排序，并保留人工删除/移出精选的入口。\n- 不将 41 张样本当独立真值；P3 仅报告前后回归变化和失败样本覆盖。\n- 必须保留 CPU 可运行路径；设备不可用时自动降级，不把 NPU 或 GPU 写死。

## 边界

- 当前 41 张样本来自用户照片和工程筛选，缺少独立人工金标准。\n- 模型基线均为 Node CPU 隔离实验，不能替代生产 GPU/NPU 性能验收。\n- YOLOX、CLIP 和 LAION 输出是候选信号，不代表真实召回率、准确率或用户满意度。\n- 本报告不修改生产主链路、不改变网页入口、不删除原图。
