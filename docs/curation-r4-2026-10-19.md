# R4 固定实施细则：模型提示与精选审美

## 边界
只复用本机已有 LAION/CLIP 与 MUSIQ-AVA 权重，不下载更多候选、不训练模型、不把大模型自报分当审美真值。专用评分器仍为CPU隔离运行，不假称已使用NPU/GPU。通用视觉模型按网页配置运行，原图不删除、不移动。

## 固定顺序与停止点
1. [x] U1 模型选项支持悬停、键盘聚焦和触屏点击查看建议；自动安全选择也有独立提示；显示速度、安装状态和安全门槛，手机提示不越界。证据：`artifacts/r4-advice-browser-green.txt`。
2. [x] C1 排序回归通过：夜景/高调/待确认不一票否决；不使用人脸大小和类别先验；技术风险仅有界惩罚；审美分使用批次相对排名；无模型时明确技术回退。证据：`artifacts/r4-regression-1.txt`。
3. [x] C2 MUSIQ-AVA 使用224/384双尺度、最长边1024、最多2线程、CPU隔离子进程、批次上限500和超时；LAION释放后才运行MUSIQ；内存不足或依赖不可用时回退并提示。证据：`artifacts/r4-musiq-bridge.txt`、`artifacts/r4-scoring-green.txt`。
4. [x] C3 内容哈希去重；感知指纹结合颜色、画幅和信息量做保守相似分组；组内按分数保留代表，再参与全局排序；复制前再次校验源文件。证据：`artifacts/r4-groups-green.txt`、`artifacts/r4-curator-group-green.txt`。
5. [x] C4 网页显示精选阶段、进度、评分器故障提示和“为什么入选”；精选完成自动停止；人工改类、删除、刷新回归通过。证据：`artifacts/r4-quick-actions-final.txt`、`artifacts/r4-continue-regression-7.txt`、`artifacts/r4-continue-regression-8.txt`、`artifacts/r4-continue-regression-9.txt`。
6. [x] V1 固定41图 MUSIQ 新旧排序实验完成，41/41 成功，新增配置约19秒完成；共39张排序位置变化。没有独立真人偏好标签，只报告排序变化，不宣称更符合用户审美。证据：`artifacts/r4-41-comparison.json`、`artifacts/r4-41-musiq-output.json`。
7. [x] A1 已更新本文件、执行清单和唯一主流程，固定停止在“等待用户少量盲选确认”，不再继续下载模型或无限调权重。

最多一轮策略修复与一次受控41图实验已完成；模型推理成功≠审美准确。当前停止在用户盲选确认，不能代填真人满意度、功耗或分类准确率。精选模型搜索和权重调整到此停止。
