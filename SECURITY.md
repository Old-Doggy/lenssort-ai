# Security and Privacy

## Do not publish sensitive material

Please do not include any of the following in an issue or pull request:

- personal photos or screenshots containing faces;
- API keys, access tokens, passwords, or private URLs;
- absolute paths that identify a user or workplace;
- model weights, generated reports, runtime caches, or local service state.

## Reporting a vulnerability

For a security issue that could expose photos, write access to an unintended folder, leak credentials, or bypass the local-only boundary, use GitHub's private security advisory process for this repository when available. If that process is unavailable, open a minimal issue asking for a private contact channel without including exploit details.

Include the affected version, a concise impact description, and safe reproduction steps. Redact all photo content and personal paths.

## Scope note

LensSort AI is a local desktop-oriented application. The local control server is not designed to be exposed to the public internet. Keep it bound to the local machine and use the launcher defaults unless you understand the network implications.
